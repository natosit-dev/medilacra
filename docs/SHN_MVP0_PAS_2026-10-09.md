# SHN MVP-0 — documented lumbar-fusion PAS

**Date:** 2026-10-09  
**First live target:** seed 300  
**Route:** 00301  
**Service:** CPT 22633  
**Diagnosis:** ICD-10-CM M43.16  
**Documentation:** completed payer-returned LumbarSpinalFusion QuestionnaireResponse

## Purpose

This is the first step that sends MediLacra's completed DTR documentation back to the payer.

The request is built from the same synthetic reality already exercised through CRD and DTR. It does not reuse the frozen Home Health PAS fixture's clinical semantics.

The PAS request carries:

- the same Patient, Coverage and ServiceRequest identities,
- CPT 22633,
- ICD-10-CM M43.16,
- the completed QuestionnaireResponse produced from MediLacra reality,
- a Claim.supportingInfo AdditionalInformation reference to that QuestionnaireResponse,
- a self-contained PAS Bundle with relative internal references,
- route 00301 on the bundled Coverage.

The request shape follows the Da Vinci PAS request-bundle/Claim structure and the current Da Vinci reference provider's PAS bundle builder.

## Documentation attachment

The completed QuestionnaireResponse is attached through the PAS AdditionalInformation slice:

```text
Claim.supportingInfo
  category = PASTempCodes#additionalInformation
  valueReference = QuestionnaireResponse/<id>
  extension-documentInformation
    reportTypeCode = X12 755#OZ "Support Data for Claim"
```

The payer's documented route-00301 lumbar-fusion behavior is:

```text
without completed questionnaire documentation -> A4 Pending + CommunicationRequest
with completed questionnaire documentation    -> A1 Certified in total
```

This is a separate documented submission. It does not mutate or resolve an earlier pend.
